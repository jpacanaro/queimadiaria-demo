# Queima Diária Demo + Dengage

Clone funcional do showcase da Dengage com identidade visual inspirada na Queima Diária.

Inclui catálogo de programas, filtros, busca, favoritos, seleção, checkout simulado, conta, inbox, recomendações, eventos e o painel Cenários Dengage. O SDK usa a configuração do projeto showcase original.

## GitHub Pages

O site é estático e funciona no caminho `/queimadiaria-demo/`. A publicação não processa pagamentos reais e é uma demonstração independente.
